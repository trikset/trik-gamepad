## На русском языке (Russian Version)

**Последнее обновление: Сентябрь 2026 г.**

Настоящая Политика конфиденциальности описывает, как приложение TRIK Gamepad
(далее — «Приложение») относится к конфиденциальности пользователей. Приложение
разработано как инструмент с открытым исходным кодом для управления роботами TRIK
и доступно по адресу
[https://github.com/trikset/trik-gamepad](https://github.com/trikset/trik-gamepad).

<a id="1-ru"></a>
### 1. Сбор и использование персональных данных

Приложение **не собирает, не хранит, не отслеживает и не передаёт** третьим лицам
никакую персональную информацию, личные данные, идентификаторы устройств или
аналитику. Приложение не интегрирует сторонние SDK для аналитики, сбора ошибок или
рекламы. Все данные о настройках приложения (например, IP-адрес робота) хранятся
исключительно локально на устройстве пользователя и никогда не передаются вовне.

<a id="2-ru"></a>
### 2. Разрешения устройства

Приложение запрашивает **минимальный набор разрешений**, необходимый для его работы:

- **Доступ к сети (INTERNET):** используется исключительно для отправки команд
  управления (по протоколам TCP/UDP) на IP-адрес контроллера робота TRIK в вашей
  локальной сети Wi-Fi. Никакие данные не передаются в интернет, облако или
  сторонним серверам.
- **Состояние сети (ACCESS_NETWORK_STATE):** используется для определения
  доступности Wi-Fi-сети.

Приложение **не запрашивает** разрешения на камеру, микрофон, геолокацию,
контакты, хранилище или уведомления. Разрешение на вибрацию не требуется на
Android 8+ (API 26+).

<a id="3-ru"></a>
### 3. Сторонние сервисы

Приложение распространяется через **Google Play** и использует **GitHub** для
хостинга исходного кода и управления разработкой. Ни одно из этих средств не
получает данные от Приложения. Приложение является проектом с открытым исходным
кодом под лицензией Apache 2.0.

<a id="4-ru"></a>
### 4. Изменения в политике конфиденциальности

Мы можем обновлять эту политику по мере изменения функций Приложения. Все изменения
будут публиковаться на этой странице. Пользователи уведомляются через примечания к
выпускам новой версии приложения.

<a id="5-ru"></a>
### 5. Контакты

Если у вас есть вопросы по поводу данного Приложения, вы можете создать обращение
(Issue) в репозитории проекта на GitHub или связаться по электронной почте:
**[support@trikset.com](mailto:support@trikset.com)**

## English Version

**Last updated: September 2026**

This Privacy Policy describes how the TRIK Gamepad application (hereinafter
referred to as the "Application") handles user privacy. The Application is
designed as an open-source tool for controlling TRIK robots and is available at
[https://github.com/trikset/trik-gamepad](https://github.com/trikset/trik-gamepad).

<a id="1-en"></a>
### 1. Collection and Use of Personal Data

The Application **does not collect, store, track, or share** any personal
information, user data, device identifiers, or analytics with third parties.
The Application does not integrate any third-party analytics, crash-reporting,
or advertising SDKs. All application settings (e.g., robot IP address) are
stored exclusively on the user's device and are never transmitted externally.

<a id="2-en"></a>
### 2. Device Permissions

The Application requests the **minimum number of permissions** required to
function:

- **Network Access (INTERNET):** used exclusively to send control commands
  (via TCP/UDP protocols) to the IP address of the TRIK robot controller within
  your local Wi-Fi network. No data is transmitted to the internet, the cloud,
  or any third-party server.
- **Network State (ACCESS_NETWORK_STATE):** used to detect Wi-Fi availability.

The Application **does not request** camera, microphone, location, contacts,
storage, or notification permissions. The vibrate permission is not required on
Android 8+ (API 26+).

<a id="3-en"></a>
### 3. Third-Party Services

The Application is distributed through **Google Play** and uses **GitHub** for
source code hosting and issue tracking. Neither of these services receives data
from the Application. The Application is an open-source project under the
Apache 2.0 license.

<a id="4-en"></a>
### 4. Changes to This Privacy Policy

We may update our Privacy Policy from time to time as the Application evolves.
Any changes will be posted on this page. Users are notified via application
release notes.

<a id="5-en"></a>
### 5. Contact Us

If you have any questions about this Application, you can open an Issue in the
GitHub repository or contact us via email:
**[support@trikset.com](mailto:support@trikset.com)**
